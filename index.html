Multi-branch inventory & point of sale, co-owned with one partner — philo.asia

A cashier here cannot stop selling because the line dropped. So the client is offline-first: an IndexedDB store with ULID keys takes every sale locally and a background sync reconciles it when the connection comes back — no lost receipts, no duplicate IDs.

DevPulse AI

Bilingual RAG document & code Q&A — GitHub

Burmese retrieval was failing. Translating the question into English for the retrieval step only — while still answering in the language it was asked in — took top-result accuracy from 1/4 to 4/4 on a measured document probe.

  • Hybrid search keeps identifiers findable — dense vectors plus BM25, with a cross-encoder reranker on top.
  • 2.5s instead of 31s to first citations, once answers streamed over SSE.
  • A 20-minute PDF embed that finishes — background ingestion with client polling instead of a request that times out.
